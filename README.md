# AI Toon World — Desktop Multi-Screen Video Wall

This version adds a desktop-style multi-screen YouTube wall.

Features:
- 4 / 6 / 9 / 12 screens selectable
- Multiple YouTube videos displayed simultaneously
- Each screen has its own YouTube player
- Start All / Stop All controls
- Multiple channel cards
- Responsive mobile layout
- GitHub Pages compatible

IMPORTANT:
Modern browsers often block automatic playback with sound for multiple videos. The site can load many players together, but the browser may require a user click before playback/sound is allowed.

To customize:
1. Open `script.js`.
2. Replace the demo `url` values with your YouTube video URLs.
3. Add more objects to the `videos` array.
4. Upload the files to GitHub Pages.

For best desktop viewing, use a large monitor and select 6, 9, or 12 screens.
